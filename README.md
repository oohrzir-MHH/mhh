# MH⋯H ｜ Where Minds Bond @ TNGS

臺南女中 課堂互動系統 —— 座位表 ＋ 計分 ＋ 點名 ＋ 學生掃碼作答。

`⋯` 是氫鍵的寫法。氫鍵單一很弱、集體很強，正好對應這套系統的核心機制：
**一個人一盞燈，全組都亮才彩虹貫通。**

## 兩個入口

| 誰 | 開哪一頁 |
|---|---|
| 老師 | `index.html`（就是這個網址的首頁） |
| 學生 | `student.html?r=教室代碼`（掃老師投影的 QR Code 就會直接進來） |

## 功能

- **座位表** —— 六組蜂巢排列，職位每輪轉一格，可直接拖曳兩個人對調位子
- **課堂互動計分** —— 點名字加分，全組都發言過就彩虹貫通
- **課堂點名** —— 出席／遲到／曠課／事假／病假／公假，外加可並存的「中途離開」標記
- **推送題目** —— 老師推題，學生手機即時作答（文字／數字／選擇題／手繪）
- **浮動工具列** —— 倒數計時、下課提醒、螢幕註記；可拖曳、可縮成小點

## 資料放哪裡

> **Firestore 是通道，Google 試算表是真相。**

| 資料 | 放哪 | 為什麼 |
|---|---|---|
| 上課當下的題目與作答 | Firestore | 要即時推播；本質是暫存，歸檔後可清 |
| 成績、評語、出缺席、歸檔作答 | 老師雲端資料夾裡的 Google 試算表 | 老師看得到、改得動、能把關 |
| 學生查得到的成績 | 同一份試算表 ＋「已發布」欄 | 老師勾了才給學生看見 |

## 關於這個 repo 裡的 Firebase 設定

`mhh-fb.js` 裡的 `apiKey` 是**公開的**，這是 Firebase 網頁版的設計 ——
它是識別碼，不是密碼。真正擋人的是 Firestore 安全規則
（學生只能寫自己那一份、讀不到別人的作答；老師名單以 email 白名單控管）。
